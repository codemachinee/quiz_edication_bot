# Образовательный Квиз-Бот

[![Python](https://img.shields.io/badge/Python-3.12-blue.svg)](https://www.python.org/downloads/release/python-3120/)
[![Docker](https://img.shields.io/badge/Docker-gray.svg?logo=docker)](https://www.docker.com/)
[![Ruff](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/astral-sh/ruff/main/assets/badge/v2.json)](https://github.com/astral-sh/ruff)

Телеграм-бот для проведения образовательных викторин, написанный на Python с использованием библиотеки Aiogram и конечных автоматов (FSM) для управления состоянием диалога.

## 🚀 Технологии

- **Python 3.12**
- **Aiogram 3**: Асинхронный фреймворк для создания Telegram-ботов.
- **UV**: Быстрый менеджер зависимостей и виртуальных окружений.
- **Ruff**: Линтер и форматер для поддержания чистоты кода.
- **Docker**: Для контейнеризации и развертывания приложения.

## 📂 Структура проекта

- `main.py`: Точка входа в приложение, инициализация бота и диспетчера.
- `handlers.py`: Обработчики сообщений и колбэков от Telegram.
- `FSM.py`: Определения состояний для конечного автомата (Finite State Machine).
- `keyboards.py`: Функции для создания различных клавиатур бота.
- `functions.py`: Вспомогательные функции.
- `structure.py`: Структуры данных, например, вопросы для викторин.
- `paswords.py`: **(нужно создать)** Файл для хранения секретных токенов.
- `pyproject.toml`: Определение зависимостей и конфигурация инструментов.
- `Dockerfile`: Инструкции для сборки Docker-образа.

## ⚙️ Установка и запуск

### 1. Подготовка

Клонируйте репозиторий:
```shell
git clone <URL вашего репозитория>
cd <имя папки проекта>
```

### 2. Конфигурация

В корневой директории проекта создайте файл `paswords.py`. В нем хранятся секретные данные.

Добавьте в него следующее содержимое, заменив заглушки на реальные данные:

```python
# Токен вашего Telegram-бота от @BotFather
tests_mk_bot = "<ВАШ_ТЕЛЕГРАМ_ТОКЕН>"

# ID чата для отправки логов. Если канала нет, можно указать ID любого
# пользователя, которому будут приходить сообщения об ошибках.
loggs_acc = "ID_КАНАЛА_ДЛЯ_ЛОГОВ" 

# ID главного администратора
admin_id = "YOUR_ADMIN_ID"

# Список ID всех администраторов
admins_list = [admin_id, "ANOTHER_ADMIN_ID"]
```

### 3. Локальный запуск

#### Установка зависимостей
Проект использует `uv` для управления зависимостями. Для их установки выполните:
```shell
uv sync
```

#### Запуск бота
Для запуска основного файла бота используйте:
```shell
uv run main.py
```

### 4. Запуск с помощью Docker

Убедитесь, что файл `paswords.py` создан и находится в корне проекта.

#### Сборка образа
```shell
docker build -t quiz-education-bot .
```

#### Запуск контейнера
```shell
docker run --name quiz-bot -d quiz-education-bot
```

#### Управление контейнером
- **Посмотреть логи:** `docker logs quiz-bot`
- **Остановить:** `docker stop quiz-bot`
- **Удалить:** `docker rm quiz-bot`

## ✨ Стиль кода и линтинг

Проект использует `ruff` для форматирования и проверки кода.

- **Форматировать код:**
  ```shell
  ruff format .
  ```
- **Проверить на ошибки:**
  ```shell
  ruff check .
  ```
После выполнения этих шагов ваш бот будет запущен и готов к работе.
